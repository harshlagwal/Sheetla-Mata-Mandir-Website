# Contributing Guidelines

Thank you for your interest in contributing to the Sheetla Mata Mandir Website! 

We welcome contributions of all kinds, including bug fixes, feature enhancements, documentation improvements, and design tweaks.

## How to Contribute

1. **Fork the Repository**: Start by forking the repository to your own GitHub account.
2. **Clone Locally**: Clone your fork to your local machine.
3. **Create a Branch**: Create a new branch for your feature or bug fix (`git checkout -b feature/your-feature-name`).
4. **Make Changes**: Implement your changes. Please ensure your code adheres to the existing style and architecture.
5. **Test**: Run `npm run lint` and `npm run build` to ensure there are no TypeScript or compilation errors.
6. **Commit**: Write clear, descriptive commit messages.
7. **Push**: Push your branch to your fork.
8. **Pull Request**: Open a Pull Request against the `main` branch of the original repository.

## Development Standards

- **TypeScript**: Ensure all new code is strictly typed.
- **Styling**: Use Tailwind CSS utility classes. Avoid inline styles unless absolutely necessary for dynamic values.
- **Components**: Keep React components modular, reusable, and focused on a single responsibility.
- **Language**: Ensure any new text is integrated into the translation system (English and Hindi).

Thank you for contributing to this open-source project!
